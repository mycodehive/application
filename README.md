### GPX Studio — GPX 웹 편집기
- https://mycodehive.github.io/application/gpx-edit/

GPX 파일을 서버에 업로드하지 않고 브라우저 안에서 직접 편집하는 도구입니다.

주요 기능:
- 기록 앞뒤의 불필요한 구간 자르기
- 잘못 든 길이나 GPS가 튄 구간을 선택하여 삭제
- 삭제 예정 구간을 지도에서 점선으로 미리보기
- 여러 날짜가 섞인 기록을 날짜 경계 기준으로 트랙 분할
- 웨이포인트(정상·갈림길·쉼터 등) 추가·수정·삭제
- 실행 취소 및 다시 실행
- 편집 결과를 표준 GPX 1.1 파일로 다운로드
- 로그인 없이 사용 가능
- 원본 GPX 파일은 변경하지 않으며 파일 데이터는 브라우저 내부에서 처리


### MovEdit — 브라우저 동영상 편집기
- https://github.writeaday.click/application/movedit/

브라우저에서 영상·이미지·자막을 타임라인에 배치하고 MP4로 렌더링하는 비파괴 방식의 간단한 동영상 편집기입니다.

주요 기능:
- 16:9 / 9:16 캔버스 선택 및 720p / 1080p 출력
- 영상·이미지 Drag & Drop 가져오기
- 타임라인 이동, Trim, Split, 클립 스냅
- 영상의 오디오 스트림 감지 시 VIDEO / AUDIO 트랙 분리
- 이미지 및 영상 Overlay, 위치 이동·크기 조절·Canvas 경계 스냅
- 자막 입력 및 위치·크기·색상·배경 편집
- Fade, Cross Fade, Slide, Wipe 전환 효과
- Undo / Redo 및 프로젝트 JSON 저장·불러오기
- ffmpeg.wasm을 이용한 브라우저 내 MP4 렌더링
- 원본 미디어를 서버에 업로드하지 않고 브라우저 내부에서 처리
