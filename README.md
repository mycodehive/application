### GPX Studio — GPX 웹 편집기
- https://mycodehive.github.io/application/gpx-edit/

GPX 파일을 서버에 업로드하지 않고 브라우저 안에서 직접 편집하는 도구입니다.

주요 기능:
- 기록 앞뒤의 불필요한 구간 자르기
- 잘못 든 길이나 GPS가 튄 구간을 선택하여 삭제
- 삭제 예정 구간을 지도에서 점선으로 미리보기
- 여러 날짜가 섞인 기록을 날짜 경계 기준으로 트랙 분할
- 웨이포인트(정상·갈림길·쉼터 등) 추가·수정·삭제
- 실행 취소 및 다시 실행
- 편집 결과를 표준 GPX 1.1 파일로 다운로드
- 로그인 없이 사용 가능
- 원본 GPX 파일은 변경하지 않으며 파일 데이터는 브라우저 내부에서 처리
