# ConvXLS

레거시 Microsoft Excel `.xls` 파일을 최신 `.xlsx` 파일로 변환하는 브라우저 도구입니다.

## 실행

https://github.writeaday.click/app/convxls/

## 주요 기능

- Excel 97–2004 `.xls` 파일 입력
- 여러 파일 일괄 변환
- `.xlsx` 출력
- 셀 글꼴 / 채우기 / 테두리 / 정렬 유지 시도
- 숫자 / 날짜 / 통화 / 백분율 등 표시 형식 유지
- 병합셀 유지
- 행 높이 / 열 너비 / 숨김 속성 유지
- 수식 / 하이퍼링크 / 셀 주석 등 워크북 메타데이터 유지 시도
- 파일별 시트 / 셀 / 서식셀 / 병합 / 수식 개수 분석
- 단일 XLSX 다운로드
- 여러 변환 결과 ZIP 묶음 다운로드
- 브라우저 로컬 처리

## 동작 방식

브라우저에서 `xlsx-js-style`을 이용해 BIFF5/BIFF8 XLS 워크북을 읽고, 셀 스타일 정보를 포함한 워크북 객체를 XLSX 형식으로 다시 기록합니다.

파일 데이터 자체는 변환 서버로 업로드하지 않습니다.

## 서식 호환성

일반적인 셀 서식 보존을 우선합니다.

- 글꼴
- 색상 / 채우기
- 테두리
- 정렬 / 줄바꿈
- 숫자 형식
- 셀 병합
- 행 높이 / 열 너비
- 수식

다만 VBA 매크로, ActiveX/OLE, 차트, 도형, 이미지, 피벗, 일부 조건부 서식처럼 셀 서식 이외의 레거시 Excel 기능은 순수 브라우저 기반 변환에서 완전 보존되지 않을 수 있습니다.

중요한 업무 파일은 변환 후 Microsoft Excel에서 최종 확인하는 것을 권장합니다.

## 사용 라이브러리

- xlsx-js-style 1.2.0
- JSZip 3.10.1
