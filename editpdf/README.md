# EditPDF

브라우저에서 PDF 파일을 열어 페이지 구성과 화면 요소를 직접 편집한 뒤 새 PDF로 저장하는 웹 기반 PDF 편집기입니다.

## 실행

https://github.writeaday.click/app/editpdf/

## 주요 기능

- PDF 파일 열기
- 다른 PDF 페이지 뒤에 추가
- 페이지 Drag & Drop 순서 변경
- 페이지 90도 회전
- 페이지 복제 / 삭제
- 빈 페이지 추가
- 텍스트 추가
- 기존 PDF 텍스트 위치를 감지하여 덮어쓰기 방식으로 수정
- 자유 그리기
- 형광펜
- 사각형 도형
- 이미지 삽입
- 손글씨 서명 작성 및 삽입
- 오버레이 이동 / 크기 조절
- 색상 / 배경 / 투명도 / 선 두께 편집
- Undo / Redo
- 확대 / 축소 / 폭 맞춤
- 편집된 PDF 다운로드

## 동작 방식

PDF 렌더링은 PDF.js를 사용하고, 새 PDF 생성과 페이지 복사는 pdf-lib를 사용합니다.

원본 PDF 페이지에 화면 편집 요소가 없는 페이지는 가능한 한 원본 PDF 페이지를 그대로 복사합니다.

텍스트, 이미지, 서명, 그리기 등 화면 편집 요소가 추가된 페이지는 브라우저에서 고해상도로 합성하여 결과 PDF에 넣습니다. 따라서 해당 페이지는 저장 결과에서 평면화(flatten)될 수 있습니다.

## 개인정보

선택한 PDF 파일 자체는 애플리케이션 서버로 업로드하지 않습니다. PDF 데이터의 읽기, 렌더링, 편집 및 결과 생성은 브라우저 안에서 수행됩니다.

단, 애플리케이션 실행에 필요한 PDF.js와 pdf-lib 라이브러리는 CDN에서 내려받습니다.

## 제한

- 암호가 걸린 PDF는 먼저 암호를 해제해야 정상 편집할 수 있습니다.
- 스캔 PDF의 글자는 실제 텍스트 객체가 아니라 이미지이므로 기존 텍스트 수정 대상으로 감지되지 않습니다.
- 기존 글자 수정은 PDF 문단을 재구성하는 방식이 아니라 원래 위치를 배경색으로 덮고 새 글자를 올리는 방식입니다.
- 편집 요소가 있는 페이지는 평면화될 수 있어 기존 텍스트 선택/검색 기능이 사라질 수 있습니다.
