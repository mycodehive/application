# 세종대 점심픽 v2

이 버전은 DB 연결 문제를 해결한 버전입니다.

## 가장 권장하는 사용법

사이트 우측 상단 `DB 연결` → `Excel 파일 직접 연결`에서

`세종대_직원용_오늘점심_식당DB_2026-09-13.xlsx`

파일을 선택하세요.

사이트가 `전체_DB` 시트를 자동으로 읽고 126개 식당을 연결합니다.

선택한 데이터는 브라우저 localStorage에도 저장되므로 같은 브라우저에서는 다음 접속에도 유지됩니다.

## 왜 기존 연결이 안 됐나?

기존 버전은 Google Sheets CSV 주소만 받을 수 있었습니다.

다음은 직접 연결되지 않습니다.

- ChatGPT의 `@파일명`
- PC의 `.xlsx` 경로
- Google Drive에 저장된 `.xlsx` 파일 URL

Google Sheets URL 방식은 원본 Excel 파일을 Google Sheets 형식으로 변환한 뒤,
링크 공개 또는 웹 게시를 해야 사용할 수 있습니다.

## 현재 지원하는 DB 방식

1. Excel 직접 선택 (.xlsx/.xls/.xlsm/.csv) — 권장
2. Google Sheets URL
3. 기본 내장 DB 126개

## 파일 구조

- index.html
- styles.css
- app.js
- app.js.txt
- restaurants.js

`restaurants.js` 덕분에 기본 DB는 `index.html`을 더블클릭해서 열어도 작동합니다.

Excel 직접 읽기는 SheetJS CDN을 사용하므로 최초 실행 시 인터넷 연결이 필요합니다.


## v2.1 변경사항

- `지도 보기` 버튼을 Google Maps가 아닌 네이버지도(`map.naver.com`) 검색으로 변경했습니다.
- 검색어는 `식당명 + 주소`를 사용합니다.

## v2.2 변경사항

- 추천 개수를 1곳 / 2곳 / 3곳 중 선택할 수 있습니다.
- 기본 추천 개수는 3곳입니다.
- 동일 추첨에서 같은 식당은 중복되지 않습니다.
- 조건에 맞는 식당이 2곳뿐이면 자동으로 2곳만 추천합니다.
- 다시 뽑기를 누르면 최대한 직전 추천 식당을 피해서 새로 추첨합니다.
- 각 추천 식당의 지도 버튼은 네이버지도 검색으로 연결됩니다.
